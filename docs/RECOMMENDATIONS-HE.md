# המלצה: CRM לתפעול, WordPress לשיווק ו־Voice AI כשירות נפרד

לעסק MasterLocknKey בתחילת דרכו הייתי עובד עם שלושה רכיבים: המערכת הזו לניהול לקוחות, עבודות, מלאי וחשבוניות; WordPress לאתר הציבורי; וספק קול ייעודי לטלפוניה. חיבור האתר נבנה כעת. החיבור ל־Retell הוכן לקליטת אירועים עתידית ונשאר כבוי.

זו בחירה הגיונית אם יש בעל מקצוע שמתחזק PHP, מסד, גיבויים ועדכוני אבטחה, ואם חשוב להתאים את חישובי העמלות והעבודות לעסק. ל־CRM הזה יש קוד קיים שימושי, אבל האחריות לתפעול ולאמינות תהיה שלנו. לפני שימוש עסקי יש להשלים בדיקות בחשבון האחסון ותהליך גיבוי ושחזור.

## חלופה שאפשר לבחון בפרויקט נפרד

אם המטרה היא להתחיל מהר עם פחות תחזוקת תוכנה, הייתי בוחן מערכת Field Service קיימת כגון Jobber או Housecall Pro. יש לבדוק בחבילה הרלוונטית API, יצוא נתונים, עמלות טכנאים, מסמכים, מדינת פעילות ועלות. איני מניח שכל התכונות או החיבורים זמינים בכל מסלול. האתר והספק הקולי יכולים להישאר נפרדים גם במסלול הזה, עם מתאם למערכת שנבחרה.

אם בעתיד נרצה מנוע תעדוף מתקדם, כלים בזמן שיחה או שירות לכמה עסקים עצמאיים, הייתי בונה שירות אינטגרציה נפרד עם API מוגבל והרשאות מפורשות. SiteGround ימשיך לשרת PHP ואת האתר; שירות האינטגרציה יוכל לרוץ על תשתית המתאימה לעיבוד רציף ולתורים.

## איך הייתי מתקדם

1. התקנה חדשה, פרטי עסק אמיתיים ובדיקה ידנית של תהליך עבודה מלא.
2. חיבור טופס האתר והפניות למסך אישור.
3. פיילוט קול מוגבל לאיסוף פניות והעברה לאדם, לאחר החלטה מפורשת.
4. API לשליפה מבוקרת של פרטי לקוח וכתובת שירות, עם אימות האדם המתקשר.
5. המלצת תעדוף על בסיס דחיפות, התחייבות זמן, מרחק, כישורים, זמינות וחלקים; רק אחרי בדיקת איכות — שיגור אוטומטי.

בשלב הנוכחי הוכנו שלבים 1–2 ותשתית קליטה לשלב 3. שליפה בזמן שיחה, תעדוף אוטומטי ושיגור עדיין אינם ממומשים.
